📦 EtiquetaFlow — Painel de ExpediçãoO EtiquetaFlow é uma solução centralizada para gestão e impressão em lote de etiquetas de envio para e-commerce. Ele integra múltiplos marketplaces em uma única interface intuitiva, permitindo otimizar o fluxo de expedição de mercadorias com apenas alguns cliques.🚀 FuncionalidadesPainel Unificado de Impressão: Exibe o total acumulado de etiquetas prontas para despacho.Impressão em Lote (Batch Printing): Imprima todas as etiquetas pendentes com um único clique.Integração Multicanal: Suporte nativo e sincronização com as principais plataformas do mercado:ShopeeTikTok ShopMercado LivreSincronização em Tempo Real: Monitoramento automático de etiquetas pendentes com status de sincronia (sync).Interface Dark Mode: Design moderno focado em produtividade e redução de fadiga visual no operador.🛠️ Tecnologias UtilizadasFrontend / Dashboard: Interface web responsiva e otimizada.Integrações de API: Comunicação direta com APIs de e-commerce e marketplaces.Módulo de Impressão: Processamento de documentos térmicos (ZPL, PDF, etc.).📊 Estrutura do PainelPlataformaStatus de ConexãoExemplo de FilaShopee🟢 Conectado18 etiquetas pendentesTikTok Shop🟢 Conectado9 etiquetas pendentesMercado Livre🟢 Conectado15 etiquetas pendentesTotal Geral—42 etiquetas📦 Como UsarConecte suas contas: Certifique-se de que todas as integrações com os marketplaces estejam ativas.Acompanhe a Fila: O painel recalcula automaticamente a contagem de etiquetas prontas a cada ciclo de sincronização.Execute a Impressão: Clique no botão central IMPRIMIR 42 ETIQUETAS para enviar a fila completa para a impressora configurada.🔧 Instalação e Execução (Para Desenvolvedores)# Clone o repositório
