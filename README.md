# EtiquetaFlow

Painel de automação de impressão de etiquetas (Mercado Livre, Shopee e TikTok Shop). Demonstração com dados simulados.

## Estrutura

```
etiquetaflow/
├── index.html              Estrutura da página
├── css/style.css           Estilos próprios (etiqueta, animações, painel, modal)
└── js/
    ├── tailwind.config.js  Cores e fontes do Tailwind
    └── app.js              Estado, impressão simulada, agendamento e scroll
```

## Como abrir

Abra `index.html` no navegador, com internet (Tailwind e fontes vêm por CDN).
Os arquivos precisam ficar nessas pastas, pois o HTML os carrega por caminho relativo.
