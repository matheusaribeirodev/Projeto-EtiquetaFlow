# EtiquetaFlow — Painel de Expedição

O **EtiquetaFlow** é uma solução centralizada para gestão e impressão em lote de etiquetas de expedição para plataformas de e-commerce. O sistema sincroniza automaticamente os pedidos pendentes e permite a impressão rápida de todas as etiquetas com apenas um clique.

---

## 🚀 Funcionalidades

* **Sincronização Multiplataforma:** Conexão em tempo real com as principais plataformas de venda.
* **Fila de Expedição Unificada:** Visualização centralizada do total de etiquetas prontas para envio.
* **Impressão em Lote:** Disparo de impressão simplificado para todas as plataformas conectadas de uma só vez.
* **Status de Conexão:** Monitoramento do estado da integração e do tempo desde a última sincronização.

---

---

## 🖥️ Visão Geral da Interface

A interface foi projetada para alta produtividade no ambiente de expedição:

1. **Fila de Expedição:** Exibe o número total de etiquetas prontas (ex.: *42 etiquetas*).
2. **Botão de Ação Rápida:** Botão principal `IMPRIMIR ETIQUETAS` para processar a fila atual.
3. **Detalhamento por Canal:** Contadores individuais para cada marketplace conectado.
4. **Relógio do Sistema:** Exibição contínua da hora e data para controle de turno.
